# 🍕 Simulador de Restaurante - Promesas y Async/Await

¡Mamma mia! Este proyecto es un simulador interactivo de pedidos de cocina desarrollado en **JavaScript** utilizando Programación Asíncrona (`Promises` y `async/await`), complementado con una interfaz web moderna y estilizada con los colores de la bandera de Italia.

## 🚀 Tecnologías utilizadas
* **HTML5** para la estructura de la página.
* **CSS3** (con variables, gradientes y animaciones) para el diseño visual.
* **JavaScript (ES6+)** para la lógica asíncrona de los pedidos y manipulación del DOM.

## ⚙️ ¿Cómo funciona la simulación?
Al hacer clic en el botón **"Iniciar Orden"**, el sistema ejecuta una secuencia estricta mediante promesas que simulan el tiempo de preparación de cada platillo:
1. 🥤 **Bebida** (4 segundos)
2. 🍕 **Pizza** (4 segundos)
3. 🍰 **Postre** (4 segundos)

Durante el proceso, el botón se deshabilita automáticamente, se muestra un indicador visual de carga (spinner) y se va registrando el éxito o cualquier inconveniente en una lista dinámica.
